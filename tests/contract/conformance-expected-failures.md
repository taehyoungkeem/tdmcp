# MCP Conformance expected failures

This baseline is limited to fixture-specific mismatches in the pinned
`@modelcontextprotocol/conformance@0.2.0-alpha.9` active server suite for MCP
`2025-11-25`. Production tdmcp intentionally does not expose verifier-only tools,
resources, or prompts.

A baselined scenario that passes is stale and fails CI. The harness also requires
all 20 baseline scenario names to execute and to contain an actual failure. This
separate check is required because the pinned upstream runner does not diagnose a
baseline entry that was never selected into the suite.

`tools-call-simple-text`, `tools-call-error`, and `logging-set-level` are
deliberately absent. The pinned verifier accepts tdmcp's well-formed unknown-tool
responses for the first two, and tdmcp advertises and implements logging level
selection for the third.
